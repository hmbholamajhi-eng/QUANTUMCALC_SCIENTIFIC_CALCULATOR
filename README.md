# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/hmbholamajhi-eng/QUANTUMCALC_SCIENTIFIC_CALCULATOR.git
```

## Enter Project

```bash
cd QUANTUMCALC_SCIENTIFIC_CALCULATOR
```

## Install Packages

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
